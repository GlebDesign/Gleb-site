# Бриф агенту «Производство» — сайт Глеба Жиделя

Ты верстаешь ОДИН-ДВА блока лендинга по референсу-«франкенштейну». Работаешь один, полный цикл:
замер референса → вёрстка → скриншот своего рендера → сверка → правки → сдача.
Обязательно прочитай `docs/design-agent-instructions.md` — референс измеряют, а не вдохновляются им.

## Проект
- Папка: `/Users/valerio/gleb-site`. Next.js 15 App Router, React 19, Tailwind v4, motion, gsap, lenis.
- Dev-сервер УЖЕ запущен на `http://localhost:3001` (HMR). НЕ запускай свой, НЕ трогай порт.
- Страница собрана в `app/page.tsx`, порядок блоков = порядок франкенштейна. Не меняй page.tsx.
- Общий обзор франкенштейна с комментариями клиента: `docs/refs/frankenstein-overview.png`
  (низкое разрешение, только для контекста). Твой блок — в `docs/refs/block-NN-*.png` (полное разрешение,
  референс ≈ 1440px макетной ширины, картинка 2930px ≈ 2x).
- Скриншоты: `node scripts/shot.mjs <section-id|full> <out.png> [width]`
  (прокручивает страницу, снимает блок по id). Пример: `node scripts/shot.mjs cases /tmp/cases.png 1440`.
  Проверь на 1440, 1600 и 375. Сохраняй скриншоты в `/private/tmp/claude-501/-Users-valerio-poyarche/819b63ff-0456-4ae4-beea-04c68164a19d/scratchpad/shots/`.
- Пипетка по референсу: `/private/tmp/claude-501/-Users-valerio-poyarche/819b63ff-0456-4ae4-beea-04c68164a19d/scratchpad/colors <png>` выводит доминирующие цвета.
  Точечные замеры — напиши свой Swift/Playwright скрипт, если нужно. Для замеров DOM своего рендера — playwright в `node -e`.
- Проверка типов: `npx tsc --noEmit` (должна быть чистой перед сдачей).

## Единый источник стилей
- Токены в `app/globals.css` (@theme). Цвета: `cream`, `cream-2`, `sand`, `black`, `black-2`, `olive`, `olive-2`,
  `ink`, `ink-2`, `paper`, `paper-2`, `butter`, `accent`, `accent-deep`, `accent-soft`, `line`, `line-dark`.
  Классы Tailwind: `bg-cream`, `text-ink-2`, `border-line-dark`, `bg-olive` и т.д.
- Шрифты: `font-sans` = Onest (гротеск), `font-serif` = Playfair Display (антиква, есть italic).
  Классы `.h-serif` и `.h-sans` для заголовков, `.label` для служебных подписей, `.wrap` — контейнер 1360px.
- Плейсхолдеры под ассеты: `<div class="ph" data-label="TODO: фото Глеба">` (светлый) / `ph ph-dark` (тёмный).
- Тексты ТОЛЬКО из `lib/data.ts`. Не хардкодь строки. Если нужного поля нет — добавь в data.ts
  (только свои экспорты, не трогай чужие) и отметь `// TODO: согласовать` для черновых текстов.
- Правило комментария клиента: «композиция один в один» = сетка, пропорции, отступы, поведение — пиксель в
  пиксель с референса; шрифты и цвета — из токенов. «Дизайн берём как на фото» = снимай и стиль тоже.
- НЕ редактируй `app/globals.css`, `app/layout.tsx`, `app/page.tsx`, `components/Reveal.tsx`,
  `components/SmoothScroll.tsx` и чужие компоненты. Нужен свой CSS (keyframes, сложные селекторы) —
  создай `components/<Block>.css` и импортируй его в компоненте.
- Параллельно с тобой работают другие агенты над другими блоками. Сохраняй файлы только в компилирующемся
  состоянии (сломанный HMR ломает всем). Не запускай `npm run build`.
- Не используй инструменты Browser pane (mcp__Claude_Browser__*) — панель одна на всех. Только playwright-скрипты.
- Кнопки-призывы: используй `useLeadModal()` из `components/LeadModal.tsx`:
  `const open = useLeadModal(); <button onClick={open}>…</button>`. Модалку реализует агент блока 6.
- Все секции: `<section id="…" className="scroll-mt-20 …">`. Id фиксированы (см. задание).
- Адаптив: 375 обязателен. На мобильном удерживай пропорции референса, а не «как получится».
- Доступность: alt у картинок, aria-label у иконочных кнопок, фокус-стили не ломать.

## Формат сдачи (без него работа не принимается)
В финальном ответе, коротко:
1. **Взято 1-в-1** с референса (что именно).
2. **Подставлено из токенов** (цвета/шрифты вместо референсных).
3. **Отступления и причины** (если нет — так и напиши).
4. **Запрошенные ассеты** (что и откуда клиенту прислать).
5. Пути к своим скриншотам 1440 / 375 и к референсу.
6. Список файлов, которые создал/изменил.
